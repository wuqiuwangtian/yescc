# YesCC 0.2.0

洗衣机说，每丢一只袜子，就有一只成功脱单。把这句话交给 YesCC，请社区调解员跟洗衣机谈赔偿。一次试玩里，程序让调解员找到了索赔的理由：「脱单的是袜子，落单的也是袜子。」

## 用普通 run 开始

把你的设定写进 UTF-8 文本文件 `idea.txt`。配置模型和单价后运行：

```bash
yescc run idea.txt --budget 0.005
yescc idea.txt --explain
```

默认档尽量保留你给的数量、角色和目标。想让模型改编得更大胆，可以给第一条命令加 `--creativity wild`。预算单位是美元，每次编译独立处理一份输入。已能原生编译的程序直接运行，能机械修好的错误优先在本地处理，两条路径都无需模型。

## 从 0.1.0 升级时会看到什么

- 普通 `run` 在修好程序或交付作品后，默认只展示程序输出。想知道原程序为何失败、模型采用了什么假设、是否仅回显了输入，可以用 `--explain` 读取上次报告。首次云端请求仍会提示数据流向。
- C 代码经规则处理后仍编译失败，默认档允许模型提交补丁或完整作品。产物会交真实工具链验证，报告分别记录修复、生成和创意兜底。旧的 `--play` 入口继续兼容。
- `yescc --offline run hello.c` 和 `yescc run hello.c --offline` 都可用。在源码目录或解压后的原生包中，`examples/moon_cafe.c` 可以离线回放月亮应聘夜班的作品。
