## 样本与方法

- 数据版本 `m4-v1`，固定比例：原生 50 / 规则错误 50 / 模型修复 30 / 自然语言 40 / 创意输入 30；原有 90 例合法样本继续完整回归。
- 数据 SHA-256：`d24f6ce70b73f746e932c6b932d6aeb4c2c88bff4ec1724bf7465b1c648a2ab2`。
- 当前被测源码指纹：`15ed86bf05d8e86f66f6a8fa0b2c5e430453fc930b951d4b155895b40ff5e6e3`；对四个 CI artifact 和 m4-1 真实评测 JSON 已核对一致。首轮对应 `51b0d85`，其独立指纹也已与该提交核对，不混用。
- 40 个任务至少 3 组固定行为测试，原生和参考实现均经真实工具链执行；参考程序、oracle、隐藏输入不上传被测模型。数据由协作助手整理，尚无人类逐题复核，不宣称人工标注或第三方基准。
- 原生对照 stdout/stderr/退出码；规则/模型修复须状态正确并满足行为测试；NL 要求 generated；创意要 creative_fallback、无额外 stdin/参数仍能成功输出。
- 默认离线只执行 130 例，另 70 例明确未评测。真实模式完整执行 200 例。每阶段独立最多 2 候选，暖阶段可能重新请求冷阶段失败项，不是同一任务的“两轮修复率”。
- 执行器、比较方式与费用边界见 [bench/README](../../bench/README.md)。
