# 评测记录

真实模型评测结果按执行日期存档，文件名 `YYYY-MM-DD.md`，内容至少包含：

- 被测版本、模型、工具链版本与平台
- 样本集版本与规模
- pass@1、两轮修复后成功率、意图正确率、假成功率
- P50/P95 延迟、token/费用、单个正确结果成本
- 未验证项与已知偏差

CI 不调用真实模型；本目录由维护者手动评测后提交。

当前完整基线：[2026-11-05 M4](2026-11-05.md)，包含双平台 CI、200 例真实模型冷/暖结果、首轮失败和费用；同页 M5 段记录独立失败审计、oracle 第二实现与补丁元数据修复复测。原始 JSON 以 gzip 存放在 `data/`，与文档一起保留，避免依赖 CI artifact 的保留期限。数据定义与执行方式见 [bench/README](../../bench/README.md)。

维护者反馈与 RC2 的离线同输入对照见 [2026-11-09](2026-11-09.md)，单列 8 个多错误场景、失败审计 v2 与新候选包证据，原 M4 结果不回写。
