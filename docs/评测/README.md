# 评测记录

真实模型评测结果按执行日期存档，文件名 `YYYY-MM-DD.md`，内容至少包含：

- 被测版本、模型、工具链版本与平台
- 样本集版本与规模
- pass@1、两轮修复后成功率、意图正确率、假成功率
- P50/P95 延迟、token/费用、单个正确结果成本
- 未验证项与已知偏差

CI 不调用真实模型；每项记录实际执行者、对应版本及证据来源。自动化回归、独立 AI 测试与维护者人工验收分别标注。
