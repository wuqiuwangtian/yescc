## 模型如何理解限定范围

两个未继承开发历史的子 agent 分别设计一对新输入。典当行小票是自由文本，陶窑开窑是含未定义动作的 C。每对输入只替换范围词：限定整份作品，或只限定末行。运行前确定判定方法，先严格解码 UTF-8、统一 CRLF、去掉至多一个末尾换行。整份与目标逐字比较，末行题只比较最后一行；前面是否有非空文字另计，只有暗号也符合末行题。

以 5e9223b 为基线，在两个仓库外环境安装旧开发 wheel 和本轮 wheel，两个版本均为 Python 3.11.15、同一 WSL/GCC 和相同依赖。四输入 × default/wild × 两版本共 16 项，交错运行。另两项仅用新默认档复查既有失败题。每项一次 CLI 调用，无本地缓存，未重抽。完整输入、原输出、生成 C、版本标识、逐项格式检查和模型 usage 见[试用记录](data/output-scope-2026-11-21.json.gz)。
