# ADR-0001：首版语言范围

- 状态：已接受（2026-11-03）；AI 能力范围由 [ADR-0010](0010-ai-target-language-and-capabilities.md) 修订
- 相关：[需求报告 §7](../初版需求报告.md)、[路线图 §4/§6.4](../项目路线图与发布计划.md)

## 背景

原始要求以「兼容所有编程语言」为目标。但每个语言都需要独立的工具链调用、参数透传、诊断解析与验证样本；「模型认识这种语言」不等于「原生行为一致」。在有限版本内无法对任意语言给出可验收的承诺。

## 决策

v0.1.0 只承诺 **Python / C / JavaScript 的单文件**能力，逐语言声明能力层级：

- 原生构建、规则修复、模型修复、自然语言生成、运行
- 跨文件与项目构建：不支持
- 未覆盖语言：返回退出码 101（不支持），给出友好状态，**不得**假装编译成功

「所有语言」保留为长期目标；新增语言必须同时提供适配器、样本集与验收记录，才能在能力矩阵中标注为支持。

## 后果

- 正面：首版可被逐项验收；失败状态诚实。
- 负面：早期版本会被拿来与「支持所有语言」的宣传对比；文档必须反复说明这是分期，不是最终范围。

## 后续

0.2 起按「适配器 + 样本 + 评测」三件套逐个扩展语言；扩展顺序由真实用户需求与工具链可获得性决定。
